Norway in October — aurora, rain, clouds & wind

Six October seasons (2018–2023, ERA5 reanalysis), mapped per climate zone (one per observation point, north to south) or per county. Pick a layer, then click any zone. Wind shows how fast the clouds drift. Aurora is a deterministic estimate (Kp threshold × October Kp climatology × clear-sky share) — not a forecast.

Data & completeness

Climate: Open-Meteo archive (ERA5/ICON reanalysis), October 2018–2023 averages per point. Geometry: geoBoundaries NOR-ADM1. Aurora: offline deterministic model — visible nights = 31 × P(Oct Kp ≥ threshold for latitude) × clear-sky fraction.

How to gather the missing data

Open-Meteo enforces an hourly request window, so the southern counties were saved for a single follow-up call:

  1. Wait ~1 hour (rate-limit window).
  2. node scripts/fetch-missing.mjs — one batched request fills data/raw/.
  3. node scripts/collector.mjs --check — recomputes data/climate.json (no network).
  4. node scripts/build.mjs — rebuilds this page with complete data.
